## 1. 命令面

保留现有命令，不新增聊天设置命令：

| 命令 | 权限 | 行为 |
|---|---|---|
| `地震列表 [cenc\|jma] [数量]` | 公开 | 最近地震列表 |
| `地震预警` | 公开 | 最近 EEW/情报 |
| `气象预警 [数量]` | 公开 | 最近 Jian 气象预警 |

- `.help` 保留「地震」「灾害」两个分组。

## 2. 文案与口吻

- **结构**：B Bulletin，900×1200 PNG；左侧色轨、官方抬头、标题、印章式等级、双栏字段、示意图、正文、来源/免责声明。
- **首报中性，后续达妮娅**：同一条消息的图片与文字使用同一口吻。
- **首报判定**（按事件身份，不按“第一次推送成功”）：

| 类型 | 首报（中性） | 后续（达妮娅） |
|---|---|---|
| 气象 | 首次见到 `alert_id` | 同 `alert_id` 的新正文/生效/等级更新 |
| 海啸 | 首次见到 `alert_id`，或 `number=1` | `number>1`，或同 `alert_id` 的更新/解除 |
| 台风 | 首次见到活跃 `typhoon_id` | 同一台风的新轨迹/强度更新；停编通知 |
| 地震 | EEW `report_num=1`；CENC/JMA 正式测定/情报 | EEW `report_num>1` |

- 中性版：第三人称、官方字段、无“达妮娅”，不用 emoji；保留来源与免责声明。
- 达妮娅版：1–3 句提醒/解读，仍保留关键数字、来源、免责声明；不替代官方措辞；不用夸张表情。
- 标题/等级/地区/时间/来源在两种口吻下都保留；达妮娅版可把“正文”改写成提醒，但不删关键字段。
- 图片正文与文字消息一致；图片在前、文字在后（OneBot 一条消息内图片段 + 文本）。

## 3. 过滤默认值

| 项 | 默认 | 说明 |
|---|---|---|
| 气象最低颜色 | 黄色 | 白 < 蓝 < 黄 < 橙 < 红；无法识别按黄色阈值 |
| 台风最大距离 | 1200 km | 仅在“本地过滤”开启且经纬度有效时生效 |
| 海啸最低等级 | 信息 | `解除` 始终放行 |
| 地震最小震级 | 4.5 | Wolfx CENC/JMA |
| 地震最大距离 | 1000 km | 本地过滤开启时 |
| 本地过滤 | 关 | 面板配置省市 + 经纬度；未填不启用 |
| 推送目标 | 空 | 单群 + 主人私聊；未配置不推 |
| EQSC 轮询 | 120 s | 钳制 30–600 s |
| 远程渲染 | 开、地址空 | 地址空 = 纯文字；失败回退文字 |

## 4. 聚合 / 去重 / 限流

- 气象：逐条推送；V1 不做 15 分钟窗口；同 `id` 的更新按内容键去重，允许更新推送。
- 海啸：按 `id + number + 内容` 去重；`解除` 始终放行；不补发历史。
- 台风：首轮基线不推；后续按 `id + 最新轨迹时间 + lat/lon + wind` 去重；活跃→停编推一次；列表含历史，不推从未活跃的旧台风。
- 地震：JMA 中间报不推（首报/最终报）；CENC 列表首轮基线，之后只推新事件；EEW 首报/最终报。
- 静默启动：Jian `all` 首帧、EQSC 首轮、Wolfx 列表首轮只建基线，不补推。
- 不做 V1：气象 15 分钟聚合、静默时段、多会话订阅、失败重试补发。

## 5. 图片

- 四类都用 B Bulletin；地图/台风路径/海啸图件用**内联 SVG 示意**，不接外部瓦片/官方图件（标“示意/占位”）。
- 渲染失败/未配置/超时：只发文字；不重发、不阻塞推送。
- 附件顺序：图片在前，文字在后；不单独再发一条图片。
- 图片字段缺失用 `—` 或省略；不因图片失败丢文字。

## 6. 空态 / 错误 / 离线

- 查询空态：`最近没有收到气象预警。` / `最近没有活跃台风。` / `最近没有收到海啸预警。` / `最近没有收到地震预警。`
- `灾害源状态` 显示：各源开关、令牌是否配置、最近轮询、最近错误、缓存数量、累计推送。
- 令牌缺失/源关闭：后台任务静默跳过，不刷错误；面板显示未配置。
- 数据源错误：写入状态错误并在 `灾害源状态` 展示；单次失败不 kill 任务。
