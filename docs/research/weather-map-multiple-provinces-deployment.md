# 气象地图与多省过滤部署验收

部署日期：2026-10-31（Asia/Shanghai）。开发服务器：`192.0.2.226`，项目：`/opt/qqbot`。

## 已交付

- 气象卡片采用用户确认的图标、类型、等级和右侧地图布局；雷电/强对流使用雷电图标，大风使用风图标，其余类型用通用预警图标。
- 按预警 `adcode` 或规范 ID 的行政编码加载边界，按源数据父级定位上下级区域，突出预警行政区域。海南岛局部示意排除三沙；不推断真实天气覆盖多边形。
- 边界来源为阿里云 DataV：`https://geo.datav.aliyun.com/areas_v3/bound/`；按数字编码请求，磁盘缓存 30 天。首次失败或无法匹配精确区域时显示“暂无行政边界”，保持预警卡片可用。没有外部图片或脚本进入渲染器。
- 气象图片高度随正文长度调整；超过 600 字在图内节选，随附文字保留完整官方正文，包括后续角色口吻的消息。
- 管理面板「灾害预警 → 本地过滤 → 省份（可填多个）」使用多行输入框。支持中英文逗号、顿号、分号或换行；去空、去重。仍保存为 `local.province` 字符串，兼容已有单省配置。
- 省份匹配任一关键词即通过；城市仍是附加限制，留空覆盖所选省份全域。预警等级阈值继续生效。
- 现有过滤设置完整保留，未预设新的省份；未额外发送 QQ 测试消息。

## 已知限制

边界数据仅用于行政区域定位，并非气象实况；DataV 未覆盖的编码不作猜测。慢网络下，过期缓存刷新若连续触发请求超时，5 秒总预算可能先结束，本次卡片会显示无地图（独立检查非阻断项，未扩展后台刷新机制）。预警类型、地区和正文仍显示，后续请求可重试。
