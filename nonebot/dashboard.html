编辑当前人格正文

保存前会校验空内容、NUL、UTF-8、大小（≤128 KiB）和 Jinja2 语法，失败时保留原文件。正文每次回复都会重新读取，保存后下一条回复生效，无需重启；编辑正文不会修改 models.yml 或切换当前模型。

current.jinja2 说明：当前人格正文保存在被 Git 忽略的 nonebot/templates/current.jinja2，git pull 不会覆盖它；它需要随迁移单独备份，git clean -fdx 或重新克隆会删除它。Denia／Shorekeeper 是可读预设，上游更新可能改变内容；加载预设只会复制一份，不会改动预设文件。

生效方式：正文文件每次渲染都会重新读取，替换 current.jinja2 无需重启；只有 models.yml 的 template 字段首次从预设切换为 current 时，才需要重启机器人或在主人私聊发送 .model reload。称呼和主人信息仍读 configs/templates.yml。
